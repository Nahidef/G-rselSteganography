# GorselSteganography

JPEG resim dosyalarına DCT (Discrete Cosine Transform) temelli steganografi ile mesaj gizleme ve çözme yapan bir Windows Forms uygulaması.

## Özellikler
- JPEG (JPG) resim dosyasına mesaj gömme
- JPEG dosyadan mesaj çıkarma
- Görsel bozulmayı en aza indirme (frekans uzayında saklama)

## Kullanım
1. Mesajı yazın ve JPEG dosyası seçin.
2. `Görsele Mesaj Göm` butonuna tıklayın.
3. `Görselden Mesaj Çıkar` ile gizli mesajı elde edin.

## Gereksinimler
- .NET Framework 4.7.2 veya üstü
